# 外壳重构：单顶栏、抽屉、紧凑页脚与超宽阅读栏

> 取代 ADR-0001 的「顶栏 + 常驻左栏」与 ADR-0004 的左栏、抽屉、页脚安排；ADR-0005 保留左栏的前提也随之取消。分类目录在归档页顶部（ADR-0005）不变。

## 决定

### 一条顶栏

- 公开站不再有左栏。顶栏是唯一常驻外壳：岛形标 + 站名、`首页` / `归档` / `推文` 三个主链接、搜索框、语言切换与主题切换。
- 主链接从 `归档` 开始改为包含 `首页`；当前栏目的标记仍然只标当前项，首页按精确路径匹配。
- 语言切换从栏底的三枚文字链接改为顶栏的一枚下拉：`中文 ▾` / `English ▾`，展开后列出可用语言并标出当前项。移动端抽屉里同样是一枚下拉，面板向上展开。
- 主题从三枚图标的分段开关改为单按钮循环：跟随系统 → 浅色 → 深色 → 跟随系统。按钮的 `aria-label` 与图标随当前主题变化，不再有 `aria-pressed` 的分段组语义。
- 搜索框在 ≥64rem 直接留在顶栏；<64rem 顶栏放一枚搜索图标，抽屉里放完整表单。这枚图标是手机上的唯一一键搜索入口，不是旧的侧栏/页脚「搜索」链接。

### 移动端抽屉

- <64rem 顶栏为站名 + 搜索图标 + `菜单`。
- `<details>` 抽屉仍无客户端状态：完整搜索表单、`浏览` 微标签、`首页` / `归档` / `推文`、语言下拉与主题按钮。
- 抽屉面板挂在 sticky 顶栏下方，高度超过视口时在面板内滚动。

### 紧凑页脚

- 页脚从三条横带（刊头 + 刊语、四个链接、年份 + 回到顶部）改为一条紧凑的署名栏。
- ≥48rem 为一行：左侧站名与一句刊语，右侧 `归档` / `推文`、年份与「回到顶部」。
- <48rem 为两行：站名 + 两个栏目；年份 + 「回到顶部」。刊语在手机上隐藏，不再占一整行。
- 顶栏、内容与页脚共用同一条 80rem 居中列；≥64rem 时内容区左右各 2.5rem，文字边缘落在 75rem。

### 超宽屏的阅读栏

- 内容列上限从原来的窄栏改为 80rem（1,280px）。
- 长文页在 ≥80rem 从 56rem（896px）放宽到 72rem（1,152px）；封面、页头与目录的栏边随之外扩。
- 正文、标签与上一篇/下一篇的测量宽度从 65ch 放宽到 72ch；正文仍然有明确上限，不随视口无限拉伸。目录继续停在右侧栏边，不进入正文流。

## 理由

- 左栏为了分类树占掉 256px，而分类树已经在 ADR-0005 移入归档；栏里只剩三个主链接、语言与主题，用一个常驻栏换这些内容不划算。去掉后正文列可以在同一屏上得到更多宽度，窄屏也不再需要为左栏让位。
- 顶栏本来就在每一页常驻，身份、导航、搜索与设置在一条线上更符合「刊物刊头」的阅读顺序；移动端把同一组东西收进抽屉，而不是维护第二套导航。
- 语言是低频设置，三枚常驻文字链接比一个下拉更占地方；主题只有三项，循环按钮比三个小图标更省空间，也更容易在手机上点中。
- 旧页脚重复了刊头与刊语，纵向占掉近三行；署名栏保留必要的身份、栏目与版权，不重复首页刊头。
- 长文的 65ch 在 1,920px 屏上只有约 650px 实际宽度，两侧留白过多；72ch 仍在可读范围内，1,152px 的页面让封面与页头真正用上宽屏，同时正文不会变成横跨整屏的长行。

## 后果

- `src/app/reader/shell.css` 重写：删除 `.site-rail`、`.site-sections`、`.site-rail-heading`、`.site-rail-foot`、`.theme-switch`；新增 `.site-topbar-nav`、`.site-topbar-controls`、`.site-locale-menu`、`.site-menu-controls` 与紧凑页脚规则。
- `SiteShell` 不再渲染左栏；顶栏与抽屉共享同一份导航链接。`SiteNav` 增加首页项；`LocaleSwitcher` 改为 `<details>` 下拉；`ThemeToggle` 改为单按钮循环。
- `chrome.railLabel` 删除，`reader.nav.home` 新增；页脚刊语在手机上只隐藏、不删除，桌面仍保留。
- 顶栏、内容、页脚统一为 80rem 内容列；长文页在 ≥80rem 放宽到 72rem，正文 72ch。
- `globals-css.test.ts` 的外壳断言改为 80rem 内容列、顶栏导航与单按钮主题；长文页新增超宽断言的测试。`site-shell.test.tsx` 不再有分类树夹具，改为断言顶栏与抽屉两份导航、页脚与当前项。
- 移动端顶栏的搜索图标保留，因此「搜索」仍有一个图标入口；这是为 <64rem 保留的一键路径，不与旧的独立「搜索」链接等同。

**Considered Options**

- 保留可收起的左栏：多一层客户端状态与持久化，而站内只有作者与匿名读者；分类树已经不在栏里，收起的收益更低。
- 把主链接与设置都塞进顶栏，不做抽屉：手机宽度放不下搜索、三个链接、语言与主题，最终仍要一个菜单。
- 顶栏只放站名与菜单，导航全部进抽屉：桌面会浪费顶栏的横向空间，也让常驻导航退化。
- 长文页继续用 896px、只把外壳放宽：封面与页头仍然窄，超宽屏的留白没有解决；只把正文拉到满屏则行宽过长。
- 页脚保留三行、只缩小字号：纵向占用仍然接近三行，重复刊头的问题没有解决。
