# Cover 是 Article 上的语言中立显式字段

每篇长文一个 `coverAssetId`，挂在 `Article` 而不是 `ArticleTranslation`，由作者在编辑器里显式选择。

同一作品的所有语言版本共用一张题图——和 `defaultLocale` 一样，它属于作品，不属于某一语言的正文；作者不会为同一篇长文的两种语言配两张题图。显式选择而不是「从正文第一张图派生」，是因为派生会把编辑器的图片位置变成一条隐式契约：作者无法在不移动图片的情况下换封面，也无法为一篇以代码开头的长文指定题图。

**Considered Options**

- 不加封面：零迁移，但参考站「16:10 封面 → 标题 → 摘要」的卡片解剖在首页与列表页落不了地。
- 保存时从正文首图派生 `coverAssetId`：零编辑器改动，但换封面要动正文，且无图文章永远没有卡片图。

**Consequences**

- 一次迁移（`article.cover_asset_id`）、资源引用登记、编辑器元信息面板新增选图控件。
- 「没有封面的长文」是必须设计的状态：卡片与长文头部都要有回落版式，不能只做有图的版本。
- `Article` 删除或换封面时，旧资源进入既有的「未引用图片」流程，不新增清理规则。
