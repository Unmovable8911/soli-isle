# 编辑设计刷新：暖纸底色、顶栏刊头、页脚与栏边目录

> 左栏与抽屉的分类树已由 ADR-0005 移除，分类目录移入归档页顶部；外壳其余部分不变。

这次刷新把公开站从「有设计系统」推到「像一份刊物」。它改的是外壳与版式，不是功能契约：发布、翻译回退、信息流只收推文、无互动、无订阅，全部不动。

## 决定

### 颜色：暖纸与墨

`tokens.css` 的八个角色全部换值：

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| `--bg` | `#f8f5ef` | `#111110` |
| `--surface` | `#fffdf9` | `#1a1917` |
| `--fg` | `#1a1815` | `#f2eee6` |
| `--muted` | `#6a645b` | `#a8a29a` |
| `--border` | `#e6e0d5` | `#2a2825` |
| `--border-strong` | `#857e72` | `#7d766b` |
| `--accent` | `#2f5c45` | `#86c5a0` |
| `--on-accent` | `#fbf9f4` | `#0d120f` |

zinc 是控制台的灰；一份被读一个小时的东西应该是纸。所有登记的配对仍由 `globals-css.test.ts` 逐对实测（最紧的一对 `--muted` on `--bg` 是 5.38:1，`--border-strong` on `--bg` 是 3.69:1）。颜色仍然只存在于 `tokens.css`。

### 外壳：刊头回到顶栏

ADR-0001 把刊头放在左栏。刷新的判断是：顶栏既然在每一个公开页上常驻，就该承担身份；左栏从导航开始，而不是在 64px 之下把站名重复一遍。于是：

- 顶栏（64px，sticky，半透明纸底 + hairline）：岛形标 + 站名 → 搜索胶囊 → 主题三段图标开关；移动端为站名 + 菜单。
- 左栏（256px）：`浏览` 微标签、四个主链接、完整分类树、栏底一句刊语与语言切换。
- 移动端抽屉：搜索框、同一份导航与分类树、语言与主题。`<details>`，无 JS。
- 页脚：刊头、一句刊语、四个主链接、年份与「回到顶部」。每个公开页都以此收尾。

左栏保留（分类树需要常驻空间，见 ADR-0001）；变的只是刊头位置与页脚的存在。

### 首页

- 刊头：站名（48 / 64 / 72px Lora）与右侧刊语共用一条 hairline。
- `最新长文` 微标签 + 主推：文字 5 / 封面 7 分栏，封面 4:3，无卡片边框。
- `更多长文` + 卡片网格（1 / 2 / 3 列，90rem 才到三列）；有封面的卡片只由 3:2 的裁切图与文字构成，无封面的卡片变成 `--surface` 上的描边文字版。

### 长文页

- 页头取满 896px 栏宽，H1 最大 20ch，正文 65ch 与页头左边缘对齐。
- 目录：<80rem 为正文上方的描边卡片；≥80rem 移到右侧 13rem 栏边并 sticky，正文与目录同屏。
- 正文增加短 accent 规则作为 h2 的开头；首字母下沉只作用于 `:lang(en)`（汉字首字下沉会把「一」这样的字压成一条横线，因此中文不做）。
- 表格改为横线制；提示块、折叠块、脚注、代码块重新定尺度；标签区带 `标签` 微标签；上一篇/下一篇为带箭头的卡片。
- 打印：外壳、目录、标签、翻页不打印；正文与链接保留下划线。

### 信息流

- 42rem 栏在阅读区居中；≥48rem 起时间进入 7rem 的左侧日期栏，页头也取同一条栏，标题与 Post 正文对齐。
- 图集计数器改为图片上的胶囊（左下），不再在图下方占一行。
- 仍然没有任何悬停位移：Post 不是入口。

### 浏览页

- 页头：H1（40 / 52px）、可选刊语、计数微标签、hairline。
- 分类索引从胶囊行升级为卡片目录（`auto-fit`，每格一个分类名与计数）。
- 归档保持索引式行列表，行高与字号加大。
- 搜索页把「找到 N 篇…」作为结果计数，任何查询（包括零结果）都会显示。

### 后台

不重排布局。登录卡加岛形标、更大的圆角与投影；顶栏站名加岛形标；其余由 token 自动跟随。

## 后果

- `globals-css.test.ts` 中描述旧几何的断言随设计更新：卡片 3:2、网格 90rem 三列、页头 40/52px、信息流页头留白、刊头位置、目录栏边等。对比度、触控、字号下限、reduced-motion、无死规则这些**行为契约不变**。
- 新增可访问名称：主题开关的三个按钮由 `aria-label` 命名（图标可见，文字隐藏）；页脚导航有 `aria-label`。新增文案在 `zh.json` / `en.json` 同步。
- 没有新增颜色角色、没有新增客户端状态、没有引入字体或图标依赖：岛形标与图标是内联 SVG。

**Considered Options**

- 去掉左栏、把导航放进顶栏：能腾出 256px，但分类树会降级成下拉，编辑式版式失去结构依托（与 ADR-0001 同一判断）。
- 保留顶栏原样（只有搜索框）：顶栏会在每个页面上留下一条 64px 的空白条，这是「没设计完」最明显的信号。
- 用 Tailwind / 组件库做这次刷新：与 ADR-0003 的对比度门禁冲突；CSS 契约测试读不到颜色。
