# 公开站外壳：顶栏 + 常驻左栏；后台保留顶栏

公开站在 ≥64rem 使用 sticky 顶栏（唯一内容是常驻搜索框）加 256px 常驻左栏（刊头、主链接、分类树，语言与主题置于栏底）；<64rem 为顶栏加原生 `<details>` 抽屉。管理后台保留横向顶栏导航，只统一样式，不做左栏。

理由是分类树只有在常驻栏里才可读——塞进顶栏只能做下拉，而它是一棵树；而编辑器自身的「写作区 + 20rem 侧栏」在 1024–1280 屏上经不起再切掉 256px，后台的第一需求是写作宽度，不是外壳同构。

**Considered Options**

- 只保留顶栏：改动最小，但分类树降级为下拉，编辑式版式缺少结构依托。
- 顶栏 + 可收起左栏（参考站的 `Sidebar view`）：多一层客户端状态与持久化，而这个站只有作者与匿名读者，不值得。
- 参考站完整三段式（左栏 + 右栏 320px）：右栏承载的是读者设置、书签、赞助、捐赠，soli-isle 一个都没有，整列不移植。

**Consequences**

- 每个公开页面的栅格、skip link 位置与焦点顺序都改变；`site-nav` 从顶栏移入左栏。
- 移动端抽屉用 `<details>`，不引入 JS；移动端顶栏只剩站名与菜单。
- 后台与公开站的统一感由 token、字体、按钮、表格、空状态承担，而不是外壳。
