# Soli Isle — UI 重构（编辑式）

## 目标

把公开站从「能用的骨架」做成一本有编辑设计的个人刊物；后台统一到同一套视觉语言。判断标准：拿一篇真实长文和一段真实信息流，手机与桌面各看一遍，不再觉得这是后台。

功能契约不动——发布、翻译回退、信息流只收推文、无互动、无订阅，全部以 `docs/specs/001-soli-isle.md` 为准。本 spec 只增加两样东西：`Cover` 字段（见 ADR-0002）与长文目录。

## 参考站的可验证值

Enova（Ghost 主题）的实测：Lora 衬线标题 + Inter 正文；zinc 近单色 + 深绿 `#3D7A5B` 点缀；256px 左栏 + 320px 右栏（右栏不移植）；卡片 16:10 封面、12px 圆角、1px 发丝线、悬停上浮；10px/0.1em 大写微标签；正文 65ch。这些数字构成了下面的设计系统，而不是逐像素复刻。

## 设计系统

### 字体

- 拉丁：自托管 **Lora Variable**（标题、刊头，400–700）与 **Inter Variable**（UI、正文，100–900），latin 子集 woff2，置于 `public/fonts/`，`font-display: swap`，不走外部 CDN。
- 中文：走系统栈。标题 `"Lora", "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC", serif`；正文 `"Inter", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。汉字自动落到栈内下一项，不需要为元素写两套规则。
- `:lang(zh)` 单独调：正文行高 1.9、字距 0.01em；标题行高 1.4、字距 0（负字距只属于拉丁）。

### 颜色

八个颜色角色，仅存在于 `tokens.css`。浅色/深色各一套：

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#fafafa` | `#09090b` | 页面底 |
| `--surface` | `#ffffff` | `#18181b` | 卡片、浮层、登录框 |
| `--fg` | `#09090b` | `#f4f4f5` | 正文 |
| `--muted` | `#52525b` | `#a1a1aa` | 次要文字、元信息 |
| `--border` | `#e4e4e7` | `#27272a` | 装饰发丝线（不承担 3:1） |
| `--border-strong` | `#71717a` | `#71717a` | 控件边界（必须 ≥3:1） |
| `--accent` | `#3D7A5B` | 提亮绿（候选 `#6EAF8E`，以测试实测为准） | 链接、引用左线、焦点环 |
| `--on-accent` | `#ffffff` | `#09090b` | 实心强调色上的文字 |

背板不新增 token：沿用 `color-mix(in srgb, var(--fg) 55%, transparent)`，与现有对话框一致。

`#3D7A5B` 在 `#fafafa` 上是 4.90:1；`#e4e4e7` 在 `#fafafa` 上只有 1.22:1，所以装饰线与控件边界必须是两个 token。

### 排版尺度

| 用途 | 尺寸 | 其他 |
| --- | --- | --- |
| 首页刊头 | 40 / 48 / 56px | Lora 700，`-0.02em`，中文走宋体 |
| 长文 H1 | 30 / 36 / 48px | 700，`-0.025em`，行高 1.25 |
| 页面 H1（归档/搜索/分类/标签） | 36 / 48px | 700 |
| 卡片标题 | 17px | 700，行高 1.375 |
| 卡片摘要 | 14px | 行高 1.625，三行截断 |
| 元信息 | 12px | `--muted`，14px 是关于可读性的下限不是上限 |
| 微标签（kicker） | 10px | 700，大写，字距 0.1em |
| 长文正文 | 18px | 行高 1.78，测量 65ch |
| UI 正文 | 16px | 行高 1.5 |

### 空间、圆角、线

8px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64 / 96。卡片内边距 20px，栅格间距 32px，发丝线 1px。圆角：封面 8px，卡片与正文图 12px，胶囊 999px。

### 动效

全局 300ms ease-out；按钮 `cubic-bezier(.23,1,.32,1)`；卡片悬停上浮 4px 并加深阴影；封面悬停放大 1.03（500ms）；标题悬停转 `--accent`；主题切换 200ms 过渡。只作用于首页与列表页的卡片网格，**信息流不加**。全部包在 `prefers-reduced-motion` 查询内，契约测试强制。

## 页面

### 外壳

- **≥64rem**：sticky 顶栏（64px，1px 底边框，唯一内容为常驻搜索框，`GET /search?q=`，无 JS）＋ 256px 常驻左栏。左栏：wordmark（链到首页）→ 主链接（分类、归档、推文、搜索）→ 分类树（全展开、按层缩进 12px、当前项 `aria-current="page"`）→ 栏底：语言切换 + 主题三段控件。左栏 sticky，自身滚动。
- **<64rem**：顶栏只剩站名与菜单按钮；菜单用原生 `<details>`，内含主链接、分类树、语言与主题。不引入客户端状态。
- 面包屑留在分类页与长文页，不进顶栏。
- skip link 仍是文档第一个可聚焦元素，焦点顺序：skip → 顶栏 → 左栏 → 主内容。

### 首页

刊头（大号 wordmark + 一句 dek，发丝线收尾）→ 主推（最新一篇：≥64rem 为「文字 5 / 封面 7」分栏，窄屏堆叠；kicker、标题、三行摘要、元信息）→ 其余长文的卡片网格（≥80rem 三列、≥64rem 两列、其余一列，最多 20 篇）。不做分类分区，不出现推文。无内容时刊头 + 一句空状态，不渲染空网格。

### 长文页

kicker（分类）→ H1 → dek（摘要）→ 元信息（发布日期 · 本文语言版本 pills）→ 封面（**原比例、不裁切**、居中、最大高度 80vh）→ 目录（仅在正文有 ≥3 个 h2 时出现，h2/h3 两级，服务端渲染锚点）→ 正文（896px 容器、65ch 测量）→ 标签 → 上一篇/下一篇。翻译缺失的提示沿用现状，换样式。图集/灯箱行为不变，只换视觉。

### 分类、标签、搜索、归档

- 分类、标签、搜索：页面头（H1 + 计数）→ 卡片网格（同首页密度）→ 分类页额外一行子分类胶囊。搜索页保留表单、结果摘要与 `<mark>` 高亮；搜索结果的卡片摘要优先显示正文片段。
- 归档：按月分组（月份标签 12px 大写 + 该月计数），组内为行式列表：日期列 + 标题 + 分类，无封面，行间发丝线。

### 信息流

42rem 单列。发丝线分隔的流，无卡片框：微标签时间 → 正文 → 横向图集 → 标签。图集保留 85% 宽、手机 4:5 / 桌面 16:9、圆角 12px、`3/9` 序号与方向键。「展开全文」与折叠渐变保留。底部「加载更早」为居中的幽灵胶囊。标签筛选在页头。整条流没有任何悬停位移。

### 后台

保留横向顶栏导航（sticky，56px）：wordmark + 后台徽标 + 六个入口 + 退出。所有页面统一页头（H1 + 描述 + 右侧主操作）。表格：12px 大写表头、发丝线行、操作按钮为小型幽灵按钮；发布状态用文字 + 圆点，不引入新色。表单：12px 标签、`--border-strong` 输入框、统一焦点环。编辑器内部布局不动，只换视觉：工具栏胶囊化、写作面板 `--border-strong` + 12px 圆角、元信息面板卡片化、发布面板主按钮用强调色。登录页：页面底上居中一张 24rem 卡片，wordmark 在上。

## 数据：Cover

`article.cover_asset_id`（可空，外键 → `asset`，`on delete set null`）＋ 迁移。资源引用登记沿用 `asset_reference`。编辑器元信息面板新增「封面」选图（复用现有 asset picker）；卡片与长文头部读它。没有封面是合法状态。旧资源按既有「未引用图片」流程处理。

## 实现约定

- **CSS**：`tokens.css` → `base.css` → `reader/*.css` → `admin/*.css`，`globals.css` 只做 `@import`。契约测试读取 tokens 文件做对比度断言，读取全部被导入文件做规则断言；新增 token 必须登记配对（`fg/bg`、`muted/bg`、`accent/bg`、`on-accent/accent`、`border-strong/bg`）。
- **i18n**：新增文案 key（封面、目录、菜单、搜索框 placeholder、栏目标题等）在 zh/en 两份 JSON 同步；缺 key 仍应构建失败。
- **Seed**：`npm run seed:demo`，仅本地（`NODE_ENV=production` 拒绝执行）。内容：一篇元素齐全的长文（封面、h2×4、图、代码、公式、提示块、折叠块、表格、脚注）＋ 一篇无封面长文 ＋ 5 条推文（含一条多图、一条超长）＋ 嵌套分类 ＋ 标签 ＋ 一篇英文长文以覆盖语言切换。图片默认由 `sharp` 生成低饱和占位图（无第三方素材），支持 `--images <dir>` 用作者自己的图替换；全部经真实上传管线生成变体。
- **不做**：不引入 Tailwind / CSS Modules / 组件库；不加订阅、会员、书签、阅读进度、阅读字号、作者信息、阅读时长、分享按钮；不新增检索或路由（`/tags` 索引页不在本次范围）。

## 验收

1. `globals-css.test.ts` 通过：新 token 每个配对的对比度、控件边界、44px、14px、焦点环、reduced-motion 容器。
2. 既有测试全绿（组件、服务、HTTP、迁移）。
3. seed 后目视走查 360 / 768 / 1024 / 1280 / 1536 五个宽度，zh 与 en 各一遍；有封面与无封面两种长文都看。
4. 键盘走查：skip link、左栏、移动端 `<details>` 菜单、目录、灯箱、信息流图集。
5. 关闭 JS 后：导航、搜索表单、移动端菜单、目录锚点仍可用。
6. 深浅色各一遍，且首屏无主题闪烁。

## 分批

- **A（设计检查点）**：01 基座 → 02 外壳 → 03 首页 → 04 长文页。交付后先看方向，再继续。
- **B**：05 列表与归档 → 06 信息流。
- **C**：07 后台与登录 → 08 收尾（空状态、404/410、错误页、全量对比度与目视抓漏）。

## 风险

- 中文字体走系统栈，Windows 与 macOS 的观感会有差异；若不可接受，再讨论子集化方案，不在本次范围。
- 左栏在 64rem 附近会挤压内容，长分类名需要换行而不是截断。
- 封面在卡片上裁切、在长文头部不裁切——两处不一致是故意的，和「推文图集裁切、长文图片完整」的既有立场一致。
- 深色强调色必须实测，候选值只是起点。
- 占位图不利于判断摄影质感；检查点可用自己的图替换。
- Lora 与 Inter 均为 OFL，需在 `public/fonts/` 放许可说明。
