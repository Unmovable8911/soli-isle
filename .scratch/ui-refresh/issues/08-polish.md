## Resolution

**resolved** — merge `d2185be` (分支 `ui/08-polish`；合并时 86 文件 / 950 测试)。

- 空状态统一为 `EmptyState`（标题 + 一句话 + 可选操作），**在只有迁移、零行的新库上逐条实测**：首页 zh/en、分类索引、无文章的分类、无文章的标签、搜索无结果、归档、信息流、仪表盘（长文与推文，带操作）、资源库（全部图片与未引用图片）。
- 404 / 410 / 500 各自成立且语义不混：404 = 404 + 本站外壳 + `main` + `noindex`；410 = **410** + `x-robots-tag: noindex` + `no-store`，wordmark-only 的「死胡同」文档；500 = `[locale]/error.tsx` + 重试。未匹配路由经 `global-not-found.tsx` 在服务端完整渲染。
- 删除 6 个死 class，并装上「任何组件都不渲染的 class 会让测试失败」的守卫；模板字面量拼出的四类前缀与 KaTeX 保留。
- 200% 缩放（把 CSS 视口减半）：修掉控制台单列栅格、宽表、资源网格与 uploader 的溢出。**我独立复测：公开站 96 次、控制台 84 次检查，零溢出。**
- 三个目视缺陷修复并实测：左栏 wordmark 从 `rgb(0,0,238)` 加下划线变为 `rgb(9,9,11)` 无下划线；长文头部从 flex 行改回块级，kicker 回到 H1 之上；`header nav a` 与 `.reader-tags a` 改为 token 取色。

**已知限制（已写入 spec 实现备注）**：动态页面在流式输出后才判定 `notFound()`，Next 15 只能返回客户端错误文档，所以「未知 Slug」的 404 在关闭 JS 时没有 `main`（本轮之前更差：整页无样式）；开启 JS 后是本站的 404 页。要彻底服务端化需要在 middleware 缓存已发布 Slug 清单，本次不新增该路由。
