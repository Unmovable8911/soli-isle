# 08: 收尾 — 空状态、404/410、错误页、全量走查

**What to build:** 把新设计里「没有内容」的每一处都补上，并做一次全量验收。

- 空状态统一为「标题 + 一句话 + 可选操作」，覆盖：首页、分类、标签、搜索无结果、归档、信息流、资源库、仪表盘。
- 404（未知 Slug）、410（永久移除）、错误页换新视觉，保留各自的响应语义与 `noindex`。
- 删除死代码：旧 class、被替换的 token、不再引用的样式规则。
- 全量走查：360 / 768 / 1024 / 1280 / 1536 五个宽度，zh 与 en，深浅两套，有封面/无封面，浏览器缩放 200%。
- 更新 `.scratch/ui-refresh/spec.md` 的实现备注与 `CONTEXT.md`（若词汇有变化）。

**Blocked by:** 03, 04, 05, 06, 07

**Status:** ready-for-agent

- [ ] 每个空状态都能从 seed 之外的「空库」状态直接看到，不需要构造特殊数据。
- [ ] 410 与 404 的响应语义不同，且都不进入索引。
- [ ] 没有遗留的 `color-mix` 控件边界，没有未登记的 token。
- [ ] 关闭 JS、200% 缩放、`prefers-reduced-motion` 三种条件下页面都成立。

## Comments
