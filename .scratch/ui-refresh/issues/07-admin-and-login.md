# 07: 后台与登录 — 设计系统对齐、封面选图

**What to build:** 后台不再是「另一个世界」，但仍是一个工作台。

- 横向顶栏导航重做视觉（sticky、56px、wordmark + 后台徽标 + 六入口 + 退出，当前项 `aria-current`），保留全部宽度给编辑器。
- 统一页头：H1 + 描述 + 右侧主操作；仪表盘、长文/推文列表、分类、标签、资源库全部套用。
- 表格：12px 大写表头、发丝线行、小型幽灵操作按钮；发布状态为文字 + 圆点。
- 表单：12px 标签、`--border-strong` 输入框、统一焦点环。
- 编辑器只换视觉：工具栏胶囊化、写作面板与 `--border-strong` 边框、元信息面板卡片化、发布面板主按钮用强调色；**不重排编辑器布局**。
- 元信息面板新增「封面」选图，复用现有 asset picker；可选择、可移除、可预览。
- 登录页：页面底上居中 24rem 卡片，wordmark 在上。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 编辑器写作区在 1280px 下宽度与改造前一致（不因外壳变化而变窄）。
- [ ] 封面选图走现有资源库流程；移除封面后文章回到无封面版式。
- [ ] 表格与表单的控件边界来自 `--border-strong`，不是装饰发丝线。
- [ ] 既有后台测试（catalogue、dashboard、confirm dialog、slash menu）保持通过。

## Comments

后台不装「编辑式」的壳：它的第一需求是写作宽度与信息密度。统一感靠 token、字体、按钮、表格与空状态，不靠左栏。
