# 04: 长文页 — 编辑式头部、封面、目录、正文排版

**What to build:** 长文页按「kicker → H1 → dek → 元信息（日期 · 语言版本）→ 封面 → 目录 → 正文 → 标签 → 上下篇」重排，并给正文换上编辑式排版。

- 封面：原比例、不裁切、居中、最大高度 80vh；无封面时不出现空白占位。
- 目录：从正文 h2/h3 派生锚点，服务端渲染；仅在 ≥3 个 h2 时出现；两级缩进；锚点 id 稳定、可重复渲染。派生逻辑是纯函数并有独立测试。
- 正文：896px 容器、65ch 测量、18px/1.78（中文行高 1.9）；引用左线用 `--accent`；代码块沿用现有 Shiki 主题；表格、提示块、折叠块、脚注只换视觉。
- 元信息行承载语言版本 pills 与降级提示（沿用现有行为），标签行与上下篇卡片重做视觉。
- 图集与灯箱行为不变。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 目录只在足够长的文章里出现，锚点跳转后焦点与滚动位置正确。
- [ ] 封面不裁切；正文图片仍按原比例完整显示，超长竖图仍有视口高度上限。
- [ ] 语言版本行如实标出哪个语言有版本、哪个是降级；切换后停留在同一篇。
- [ ] 打印或纯文本读取时，正文顺序与屏幕一致（目录在正文之前）。
- [ ] 标题、摘要、日期的语义标签与 `dateTime` 属性未被重排破坏。

## Comments

目录是**派生**的：不要存储目录、不要给正文加标记字段，也不要为了目录改动渲染器的数据结构。锚点 id 由标题文本 + 序号确定性生成，同一份 JSON 渲染两次必须得到同样的 id。
