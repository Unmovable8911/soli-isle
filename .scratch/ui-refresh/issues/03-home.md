# 03: 首页 — 刊头、主推、卡片网格

**What to build:** 首页从「H1 + 链接 + 平铺列表」变成编辑部式的首页。

- 刊头：大号衬线 wordmark（h1，不重复链接）+ 一句 dek + 发丝线。
- 主推：最新一篇已发布长文；≥64rem 为「文字 5 / 封面 7」分栏，窄屏堆叠；kicker（分类）、标题、三行摘要、日期。
- 网格：其余长文，最多 20 篇；≥80rem 三列、≥64rem 两列、其余一列；卡片解剖为 16:10 封面（`object-fit: cover`、8px 圆角）→ kicker/标题 → 三行摘要 → 元信息，悬停上浮。
- 无封面长文的回落版式：没有图区，标题上移，卡片高度靠内容撑开，不出现灰色占位块。
- 空状态：刊头 + 一句话，不渲染空网格。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 主推不是「精选」字段：它永远是最新一篇，没有需要作者维护的新概念。
- [ ] 有封面与无封面两种卡片在同一网格里对齐且都不突兀。
- [ ] 卡片整体可点、悬停有反馈，但反馈不影响文字可读性。
- [ ] 首页不出现任何推文。
- [ ] 360px 下不横向滚动。

## Comments

卡片的可点击区域是标题链接，不是整张卡片的 `div`——不要为了「整卡可点」给容器加 `onClick`，那会造出不可键盘聚焦的假链接。
