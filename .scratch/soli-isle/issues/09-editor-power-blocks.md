# 09: Editor power blocks

**What to build:** The Article editor gains tables, footnotes, math formulas, callouts, and fold blocks — insertable via slash commands and Markdown, rendered correctly in preview and on the public page — plus drag-to-reorder of blocks.

**Blocked by:** 05 — First published Article; 07 — Public article reading

**Status:** ready-for-agent

- [ ] Tables, footnotes, math, callouts, and fold blocks insert via slash command (and Markdown input where applicable) and render correctly in editor preview and on public Article pages.
- [ ] Math formulas render correctly in published Articles.
- [ ] Callouts and fold blocks render with their intended structure; a fold block starts collapsed and expands on demand.
- [ ] Blocks can be reordered by dragging.
- [ ] Undo/redo covers every new block operation.
